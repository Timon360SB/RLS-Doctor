## Overview

An early source preview of request capture, explicit local GET replay and authorization diagnostics for Supabase/PostgreSQL RLS. It is not a production-ready release or a certification of database security.

## Included

- Opt-in Node.js capture SDK and shared event schema.
- Python CLI for event validation, read-only catalog inspection and local GET scenarios.
- Console/JSON reports with evidence and expectation statuses.
- Synthetic fixtures, automated tests and bilingual project documentation.

## Known limitations

Full Supabase Auth/REST E2E, independent maintainer review and remote CI were still pending at the initial baseline. Browser capture, write replay, remote replay, HTML reports and automatic policy repair are outside this preview. Packages are used from source; npm/PyPI publication is separate.
