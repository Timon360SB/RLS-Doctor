# Как указать участие Codex в pull request

Участие в написании кода можно явно описать в PR. Для текущей работы подойдёт:

> Основная реализация кода выполнена с помощью OpenAI Codex (ИИ-помощника).
> Постановка задачи и ответственность за принятие изменений: @Timon360SB.
> Выполненные проверки и оставшиеся ограничения перечислены отдельно.

Английский вариант:

> Primary code implementation: OpenAI Codex (AI coding assistant).
> Task direction and responsibility for accepting changes: @Timon360SB.
> Executed checks and remaining limitations are documented separately.

Используйте формулировку только для изменений, к которым она действительно
относится. Она не утверждает, что человеческое ревью уже проведено.

## Автор PR, соавтор и ревьюер

Этот чат не является отдельным GitHub-аккаунтом. Описание помощи ИИ не меняет
владельца проекта или аккаунт, открывший PR. Указывать Codex как основного
помощника в реализации можно в тексте, сохраняя ответственность за принятие
изменений за реальным сопровождающим проекта.

GitHub поддерживает `Co-authored-by: Name <email>` в сообщении коммита. Для
привязки к реальному профилю нужен связанный с ним адрес. Не придумывайте
GitHub-логин или личный адрес от имени этого чата. Обычная текстовая атрибуция
не требует такой привязки. [Инструкция GitHub о соавторах](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors).

## Участие бота в ревью

1. Подключите RLS-Doctor к Codex и включите code review в настройках интеграции.
2. В комментарии к нужному PR напишите `@codex review`.
3. Дождитесь фактического ответа бота и проверьте замечания.

Это отдельный запуск Codex, а не перенос памяти этого чата. Настроенная интеграция
учитывает инструкции AGENTS.md. Автоматическое ревью не является независимым
человеческим ревью и не подтверждает прохождение CI.
[Официальная инструкция OpenAI](https://learn.chatgpt.com/docs/third-party/github).

В `.github/PULL_REQUEST_TEMPLATE.md` добавлено необязательное поле для описания
такой помощи. Оно заполняется под конкретный PR. Удалённые настройки GitHub,
участники, авторы старых коммитов и права доступа этим изменением не меняются.
